# assets — 배경 이미지

학교 자체 강의자료(`창업과 기업가 정신` 1강)에서 그대로 가져온 배경입니다.
같은 학부·같은 교수의 강의자료라 시각 언어를 맞추기 위해 함께 씁니다.

| 파일 | 쓰이는 자리 | 크기 |
|---|---|---|
| `bg-cover.jpg` | 표지 윗 띠 | 1280×518 |
| `bg-band.jpg` | 챕터 표지 · 다음 차시 · 질의응답 윗 띠 | 1280×374 |
| `bg-campus.jpg` | 본문 슬라이드 바탕 (아주 옅게) | 1280×658 |

빌드할 때 HTML 에는 data URI 로 심고, 디자인 캔버스에는 파일로 넣고,
파워포인트에는 그림으로 붙인다 (`build.mjs` 의 `ASSETS`).
