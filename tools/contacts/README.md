# 주소록 old / new 나누기

`radical8566@gmail.com` 의 Google 주소록을 **7월 말**을 기준으로 잘라
`old` · `new` 라벨 두 개로 나눈다. 폰을 바꾸며 도로 들어온 줄을 골라내려는 것이다.

## 왜 스크립트인가

주소록을 CSV 로 내려받아도 **"언제 들어왔나" 가 안 나온다.** 내보내기 파일에는
날짜 칸이 아예 없다. 그 값을 주는 곳은 Google People API 하나뿐이라,
날짜로 자르려면 API 를 거쳐야 한다.

Apps Script 로 쓴 이유는 이게 계정 안에서 도는 자리라 열쇠(OAuth 클라이언트)를
따로 만들 필요가 없어서다. 붙여넣고 한 번 허용하면 끝난다.

## 하는 법

1. <https://script.google.com> → **새 프로젝트**
2. 왼쪽 **서비스 +** → 목록에서 **Peopleapi** 를 골라 **추가**
   (식별자는 `People` 그대로 둔다)
3. `Code.gs` 내용을 지우고 [`organize-old-new.gs`](organize-old-new.gs) 를 통째로 붙여넣는다
4. 함수 목록에서 **`organizeContacts`** 를 고르고 **▶ 실행**
   - 처음 한 번 권한 허용 창이 뜬다. "고급" → "이동" → 허용
5. 아래 **실행 로그**에 숫자가 찍힌다

첫 실행은 `DRY_RUN = true` 라서 **세어만 본다.** 라벨은 안 붙는다.
대신 결과 스프레드시트가 하나 생기고 그 주소가 로그에 찍힌다 —
오래된 것부터 정렬돼 있으니 거기서 눈으로 확인하면 된다.

숫자와 기준이 맞으면 파일 위쪽의

```js
const DRY_RUN = true;
```

를 `false` 로 고치고 다시 ▶ 를 누른다. 그때 라벨이 붙는다.

## 고칠 수 있는 값 (파일 맨 위)

| 값 | 기본 | 뜻 |
|---|---|---|
| `CUTOFF` | `2026-07-31T23:59:59+09:00` | 이 시각까지 `old`, 넘으면 `new` |
| `LABEL_OLD` / `LABEL_NEW` | `old` / `new` | 붙일 라벨 이름 |
| `DRY_RUN` | `true` | `true` 면 세어만 본다 |
| `MAKE_REPORT` | `true` | 결과 스프레드시트를 만들지 |

## 알아 둘 것

- **아무것도 지우지 않는다.** 라벨만 붙인다.
  되돌리려면 주소록에서 그 라벨을 지우면 된다 — **라벨을 지워도 연락처는 남는다.**
- 기준으로 쓰는 값은 **마지막 수정 시각**이다. People API 는 "만든 시각" 을
  주지 않는다. 폰을 바꾸며 통째로 다시 들어온 줄은 그때 시각이 찍히므로
  사실상 "언제 들어왔나" 노릇을 하지만, **옛 연락처를 7월 이후에 한 번이라도
  고쳤다면 그 줄은 `new` 로 간다.** 결과 시트에서 확인할 것.
- 수정 시각을 못 읽는 줄은 `old` 로 넣고 시트에 `(없음)` 으로 남긴다.
- 사람이 많으면 몇 분 걸린다. Apps Script 한 번 실행 한도는 6분이라,
  5천 명이 넘어가면 `LABEL_OLD` · `LABEL_NEW` 를 나눠 두 번 돌리는 편이 낫다.
