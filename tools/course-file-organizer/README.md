# 과목별 강의파일 정리 도구

`G:\복구됨_F\재구성 파일\문서` 아래에 흩어진 강의 파일을
**동아방송예술대 → 과목별 폴더**로 갈라 넣는다.

```
동아방송예술대\
  1인 예술과 창업실무\
  자원관리능력개발\
  창업과 기업가정신\
  취업과 경력개발\
  문화예술콘텐츠 창업\
  00_미분류\            ← 기계가 확신 못 한 것. 사람이 본다
  분류결과.csv
  검토용_발췌.txt
```

## 왜 두 단계인가

한 번에 옮기지 않는다. 잘못 옮기면 되돌리기 어렵고,
`복구됨_F` 라는 이름이 말해 주듯 이미 한 번 잃었던 파일이다.

1. **훑기** — 파일을 읽고 점수를 매겨 `분류결과.csv` 만 쓴다. 파일은 그대로 둔다.
2. **적용** — csv 의 `분류` 칸을 그대로 믿고 폴더에 넣는다. 기본은 **복사**(원본 유지).

사이에 사람이 csv 를 고칠 수 있다. 그게 이 도구의 요점이다.

## 쓰는 법

Windows PowerShell 에서 (관리자 권한 필요 없음):

```powershell
cd <이 폴더>

# 1단계 — 훑기. 파일은 건드리지 않는다
powershell -ExecutionPolicy Bypass -File .\Organize-CourseFiles.ps1

# (분류결과.csv 를 열어 `분류` 칸 확인·수정)

# 2단계 — 복사해서 정리
powershell -ExecutionPolicy Bypass -File .\Organize-CourseFiles.ps1 -Apply

# 원본을 옮기고 싶으면
powershell -ExecutionPolicy Bypass -File .\Organize-CourseFiles.ps1 -Apply -Move
```

훑을 곳이나 넣을 곳이 다르면:

```powershell
.\Organize-CourseFiles.ps1 -Root 'G:\복구됨_F\재구성 파일\문서\PPT' -Dest 'D:\정리\동아방송예술대'
```

## Claude 에게 검토를 맡기려면

1단계를 돌리면 `검토용_발췌.txt` 가 같이 나온다.
파일마다 **안의 글자 1200자 발췌**와 기계가 매긴 점수·근거가 적혀 있다.

`분류결과.csv` 와 `검토용_발췌.txt` 두 개를 대화에 올리면
`00_미분류` 로 빠진 것과 애매한 것을 사람 대신 다시 갈라 준다.
고쳐진 csv 를 제자리에 덮고 `-Apply` 를 돌리면 된다.

## 어떻게 분류하나

파일 **이름** 과 **안의 글자** 를 같이 본다.

| 신호 | 점수 |
|---|---|
| 파일 이름에 과목 이름이 박혀 있다 | +10 |
| 그 과목에서만 쓰는 말 (`기업가정신`, `자원관리능력`, `문화예술콘텐츠` …) | +6 |
| 그 과목에서 자주 나오는 말 (`사업계획서`, `시간관리`, `자기소개서` …) | +1 |
| 다른 과목의 센 말이 같이 있다 | -2 |

- 최고점이 **3점 미만**이면 `00_미분류`.
- 1위와 2위가 **2점 차 미만**이어도 `00_미분류` — 헷갈리는 걸 억지로 넣지 않는다.
- **긴 이름이 짧은 이름을 먹는다.** `문화예술콘텐츠창업실무` 가 이름에 있으면
  `창업실무`(1인 예술과 창업실무)는 세지 않는다. 이게 없으면 두 과목이 동점으로 붙는다.

## 안의 글자를 읽는 형식

| 형식 | 읽나 |
|---|---|
| `.pptx` `.ppsx` `.docx` `.xlsx` `.hwpx` | **읽는다** (zip 안 XML 에서 뽑는다) |
| `.txt` `.md` `.csv` `.html` `.xml` | **읽는다** |
| `.ppt` `.doc` `.xls` `.hwp` `.pdf` | **못 읽는다 — 이름만 본다.** csv 의 `판단자료` 칸에 표시된다 |

구형식과 PDF 는 그래서 `00_미분류` 로 많이 빠진다. 정상이다 — 사람이 보라는 뜻이다.

## 옵션

| 옵션 | 뜻 | 기본 |
|---|---|---|
| `-Root` | 훑을 최상위 폴더 (하위까지 내려간다) | `G:\복구됨_F\재구성 파일\문서` |
| `-Dest` | 정리해 넣을 곳 | `<Root>\동아방송예술대` |
| `-Apply` | 2단계(적용). 없으면 훑기만 | 꺼짐 |
| `-Move` | 복사 대신 이동 | 꺼짐(복사) |
| `-Plan` | 읽을 분류표 csv | `<Dest>\분류결과.csv` |
| `-MinScore` | 이 점수 아래는 `00_미분류` | `3` |
| `-SnippetChars` | 발췌 길이 | `1200` |

- 넣을 폴더에 같은 이름이 있으면 `이름_1.pptx`, `이름_2.pptx` 로 붙인다. 덮지 않는다.
- `-Dest` 아래는 훑을 때 제외한다. 두 번 돌려도 정리한 것을 다시 집지 않는다.
