## 2. DB — 무엇이 실제로 올라가 있나

`0011` · `0012` · `0013` · `0014` 를 이날 SQL Editor 에서 올렸다.
REST 로 다시 물어 확인한 결과가 아래다. 전부 200 이다.

| 확인한 것 | 결과 |
|---|---|
| `students.grade` · `dept` (`0011`) | 200 |
| `student_contacts` · `session_marks` · `mark_policies` (`0012`) | 200 |
| `message_templates` · `message_log` (`0013`) | 200 |
| `message_log.channel` 에 `heyyoung_push` (`0014`) | 제약에 포함됨 |

```bash
cd web && U=$(grep VITE_SUPABASE_URL .env | cut -d= -f2-) \
        && K=$(grep VITE_SUPABASE_ANON_KEY .env | cut -d= -f2-)
for t in student_contacts session_marks mark_policies message_templates message_log; do
  echo -n "$t "; curl -s -o /dev/null -w '%{http_code}\n' "$U/rest/v1/$t?select=*&limit=1" -H "apikey: $K"
done
```

`404` 는 표가 없는 것이고 `200`(빈 배열 포함)이면 표는 있고 anon 이 못 읽는
것뿐이다. **둘을 헷갈리지 말 것** — RLS 로 막힌 것과 표가 없는 것은 다르다.

> **SQL Editor 에는 확인 대화상자가 있다.** `Run` 을 눌러도
> "Potential issue detected — Run query / Cancel" 이 뜨면 거기서 한 번 더
> 눌러야 실제로 돈다. 이걸 못 보고 앞 실행의 "Success" 를 그대로 읽으면
> **안 돌아간 것을 돌아갔다고 착각한다.** 실제로 그렇게 한 번 틀렸다.

## 5. 주소 — HTTP 는 뜨고 HTTPS 는 안 뜬다

DNS 와 Pages 설정은 끝나 있다. 막힌 것은 인증서 하나다.

```
$ openssl s_client -servername lms.miraejob.co.kr -connect lms.miraejob.co.kr:443
subject=CN=*.github.io          ← 우리 도메인 이름이 들어 있지 않다
```

GitHub 이 `lms.miraejob.co.kr` 용 인증서를 아직 발급하지 않았다.

**이건 불편함으로 끝나지 않는다.** 2026-08-23 에 실제로 사고가 났다 —
평문 HTTP 요청을 **공유기가 가로채** 설정 페이지(`192.168.8.1`)로 돌려 버려서
화면이 통째로 안 열렸다. 학교 밖 · 공용 와이파이에서 학생이 겪을 일이다.

**할 일** — 저장소 `Settings → Pages` 에서 Custom domain 을 **지웠다가 다시
저장**한다. 초록불 뒤 인증서가 발급되면 **`Enforce HTTPS` 를 켠다.**
인증서 없이 켜면 사이트가 통째로 안 열린다. 발급 여부는 위 `openssl` 한 줄로 본다.

## 6. 헤이영 — 무엇이 되고 무엇이 안 되나

교수 계정으로 직접 열어 보고 적었다. 자세한 것은
[`70-attendance-contacts.md`](70-attendance-contacts.md).

  코드에 있던 `/admin/screen/HCO0301M01` 은 404 였고, 그마저 출석부 화면 코드였다.
- **푸시는 된다** — `푸시 전송 · 컨텐츠관리 · 전송결과 · 전송통계`.
  다만 **헤이영캠퍼스 앱을 깐 학생만** 받는다. 누가 깔았는지는 알 길이 없다.
- 번호를 걷는 가장 빠른 길은 **푸시 `수신자 추가`** 다. 강좌를 고르면 그 강좌
  학생의 이름 · 학번 · 학과 · 학년 · 전화번호가 한 표에 나온다.
  맨 위 `개인정보마스킹여부` 를 끄고 통째로 긁어 `연락처 관리` 에 붙인다.
- 여전히 **이쪽이 대신 쏘지 않는다.** 공개 API 가 없고 전송 엔드포인트는 추측이다.
  제목 · 내용 · 학번 목록까지만 만들고 `메시지전송` 은 사람이 누른다.
