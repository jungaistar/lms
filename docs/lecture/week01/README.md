## week01.html 을 고칠 때

슬라이드 한 장은 `<section class="slide" data-slide="N" data-kind="...">` 하나다.
장을 더하거나 지울 때 이 구조만 지키면 아래가 전부 따라온다.

- `data-kind` 는 `cover` · `chapter` · `toc` · `content` 네 가지
- 색·글꼴은 파일 맨 위 `:root` 의 CSS 변수 한 곳에만 있다.
  **화면 코드에 색을 직접 박지 말 것** — 2주차 자료에서 뽑은 값이다
- 공용 그래픽(배경 워터마크 · 띠 · 줄무늬 · 체크박스)은 맨 위 `<svg><defs>` 의
  `<symbol>` 로 한 번만 정의하고 `<use href="#id">` 로 부른다
- 오른쪽 아래 도구 세 개 — `발표 모드`(←/→ 로 넘김, Esc 로 나감) ·
  `글 고치기`(본문을 그 자리에서 수정) · `인쇄 / PDF`

## 그래픽

전부 인라인 SVG다. 이미지 파일이 하나도 없어서 HTML 한 개만 있으면 어디서든 똑같이 뜬다.

- 성적 반영 비율 — 도넛 (9쪽)
- 과제 제출 시점 — 타임라인 (13쪽)
- 생성형 AI 활용 3단계 흐름 (19쪽)
- 챕터 표지의 원형 다이얼, 표지·챕터의 스튜디오 톤 배경

이모지는 구글 이모지(`Noto Color Emoji`)를 CDN 으로 받아 쓴다.
