# 제1강 오리엔테이션 학습자료

`창업과 기업가 정신` 1주차 오리엔테이션 자료를 **2주차 자료의 디자인 시스템**으로 다시 짠 것.
**1주차 원본 내용은 그대로 두고**, 「생성형 AI 사용 지침」 한 장(19쪽)만 새로 넣어 20장이다.

## 무엇이 들어 있나

| 파일 | 무엇 |
|---|---|
| `week01.pptx` | **편집 가능한 슬라이드 20장.** 글자·표·도형·도넛 차트가 모두 PowerPoint 네이티브다 |
| `week01.html` | 같은 내용의 완성 슬라이드. 브라우저로 바로 열린다 (파일 하나로 끝, 이미지도 안에 있다) |
| `week01.md` | Markdown (Marp 머리말 포함 — 슬라이드로 변환 가능) |
| `svg/` | 원본 PDF 의 그림 요소를 낱장 SVG 로 정리 · [목록](svg/README.md) |
| `assets/` | 원본 PDF 에서 뽑은 사진 세 장과 합성한 배경 |
| `canvas/` | 슬라이드 한 장 = 아트보드 한 장 (`.dc.html`) |
| `make-pptx.js` | `week01.pptx` 생성기 (`node make-pptx.js`) |
| `make-backgrounds.py` | `assets/bg-*.jpg` 합성기 |
| `verify-coverage.py` | 원본 PDF 대비 내용 누락 검사기 |

## 원본과의 유사성 — 기계로 확인한다

```bash
python3 verify-coverage.py <원본 1주차.pdf>
```

원본 PDF 의 모든 문장을 뽑아 글자·숫자만 남긴 뒤(글머리표 `➢ ✓ -`, 구분기호 `_ / :`,
문장부호 차이는 내용과 무관하므로 뺀다) 결과물 안에 있는지 하나씩 대조한다.

```
원본 PDF 문장 134개 대조
PPTX   134/134  = 100.00 %
HTML   134/134  = 100.00 %
MD     134/134  = 100.00 %
```

**원본에 있던 문장은 하나도 빠지지 않았다.** 새로 들어간 것은 19쪽 한 장뿐이다.

시각적으로도 원본 PDF 안에 들어 있던 사진 세 장(교문·부조정실·본관)을 그대로 꺼내
배경으로 쓴다 — 표지·챕터의 파란 띠, 본문의 옅은 워터마크가 원본과 같은 사진이다.

## week01.pptx — 무엇이 편집되나

| 요소 | 어떻게 들어 있나 |
|---|---|
| 모든 글자 | 네이티브 텍스트 상자. 글꼴 `맑은 고딕` (숫자·영문 `Arial`) |
| 주차별 계획 · 성적 비율 · 교재 서지 | 네이티브 표 |
| 성적 반영 비율 도넛 | **네이티브 차트** — 20/30/30/20 값을 PowerPoint 안에서 바로 고친다 |
| 과제 제출 타임라인 · AI 3단계 흐름 · 교재 표지 · 번호 원 | 네이티브 도형 |
| 배경 띠 · 워터마크 · dima 워드마크 · 챕터 다이얼 | 이미지 (SVG 원본은 `svg/`) |

판형은 13.333 × 7.5 in (16:9). `week01.html` 과 같은 1280×720 px 좌표계를
1 px = 1/96 in 로 그대로 옮겼다 — 두 파일의 배치가 어긋나지 않는 이유다.

다시 만들려면 `node make-pptx.js`. 좌표는 `P(px)`, 글자 크기는 `PT(px)` 로 쓴다.

## week01.html 을 고칠 때

슬라이드 한 장은 `<section class="slide" data-slide="N" data-kind="...">` 하나다.

- `data-kind` 는 `cover` · `chapter` · `toc` · `content` 네 가지
- 색·글꼴·배경 사진은 파일 맨 위 `:root` 의 CSS 변수 한 곳에만 있다.
  **화면 코드에 색을 직접 박지 말 것**
- 공용 그래픽(줄무늬·체크박스)은 맨 위 `<svg><defs>` 의 `<symbol>` 로 한 번만
  정의하고 `<use href="#id">` 로 부른다
- 오른쪽 아래 도구 세 개 — `발표 모드`(←/→ 로 넘김, Esc 로 나감) ·
  `글 고치기`(본문을 그 자리에서 수정) · `인쇄 / PDF`

## 원본에서 손대지 않은 것

원본의 문구·수치·링크·이메일은 그대로다. 아래 두 가지는 원본 그대로 두었으니
필요하면 사람이 판단해 고칠 것.

- 20쪽 「다음 차시 안내」의 **`제1강 창업과 기업가 정신`** — 2차시를 가리키는데 원본에
  `제1강` 으로 적혀 있다. 2주차 자료 표지는 `제2주차` 다
- 13쪽 과제 제출 예시 날짜 `3.15 / 3.16` — 원본의 예시 날짜
