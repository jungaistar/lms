# 04. 구현 로드맵

각 단계는 **앞 단계가 끝나야 다음이 의미가 있습니다.** 순서대로 진행하세요.

## Phase 0 — 사전 확인 (코드 작성 전)

- [ ] 접속 중인 시스템이 **운영인지 데모인지** 확인 (화면에 "Demo" 표기가 있었음)
- [ ] 운영이라면 **원격교육지원센터에 자동화 도구 사용 가능 여부 문의**
- [ ] 본인 담당 과목의 `course_id`, `class_no` 확보

> 이 단계를 건너뛰지 마세요. 여기서 "불가" 답을 받으면 이후 전부가 무의미합니다.

## Phase 1 — 세션 확보

- [ ] `npm run auth` — Playwright로 브라우저 열기
- [ ] 사람이 직접 로그인 (캡차 통과)
- [ ] 로그인 완료 감지 → `storageState`를 `.auth/state.json`에 저장
- [ ] `getSessionInfo.dunet` 호출로 세션 생존 확인

**완료 기준:** 스크립트에서 담당 과목 목록을 한 번 읽어올 수 있다.

## Phase 2 — 읽기 전용 수집

- [ ] `doListView.dunet` → 담당 과목 목록 파싱
- [ ] `doListCourseStudent.dunet` + `doGetPageInfo.dunet` → 학생 명단 + 평가항목/가중치
- [ ] `report/prof/doListView.dunet` → 과제 목록 (`report_no`, `report_seq`)
- [ ] `doMarkView.dunet` → 학생별 제출 여부 및 현재 점수
- [ ] `doFormReportMark.dunet` → 제출물 본문·첨부·현재점수
- [ ] 첨부파일 다운로드 (`data/submissions/`)
- [ ] 모든 응답 원본을 `raw_html`로 함께 저장

**완료 기준:** LMS에 다시 접속하지 않고도 로컬 데이터만으로 채점할 수 있다.

> 파서는 깨지기 쉽습니다. 셀렉터 하나가 안 맞으면 조용히 빈 배열을 반환하는 대신
> **명시적으로 실패**하게 만드세요. 조용한 실패가 가장 위험합니다.

## Phase 3 — 채점 초안 생성

- [ ] 과제별 루브릭 정의 (`grade/rubrics/*.md` — 사람이 작성)
- [ ] 제출물 + 루브릭 → Claude → `{score, reasoning, feedback}`
- [ ] 결과를 `status='draft'`로 저장
- [ ] 루브릭 만점 초과·음수 등 범위 검증

**완료 기준:** 학생별 초안 점수와 근거가 로컬에 쌓인다. **아직 LMS에는 아무것도 쓰지 않았다.**

## Phase 4 — 사람 검토

- [ ] `npm run review` — 초안을 제출물과 나란히 표시
- [ ] 점수·피드백 수정 가능
- [ ] 승인 시 `status='approved'` + 검토 시각 기록
- [ ] 미검토 초안은 Phase 5 진입 차단

**완료 기준:** 승인된 항목만 다음 단계로 넘어간다.

## Phase 5 — 브라우저 자동화 입력

- [ ] `--dry-run`으로 먼저 전 과정 실행 (저장 버튼만 안 누름)
- [ ] 채점 화면 열기 → 대상 학생 행 확인 → 점수 입력창 채움
- [ ] 저장 직전 **화면 캡처 + 이전값/새값 표시 → 사람 승인**
- [ ] 저장
- [ ] 저장 후 값 재조회하여 검증
- [ ] 감사 로그 기록

**완료 기준:** 한 학생을 실제로 채점 완료하고, 화면에서 눈으로 확인했다.
**첫 실행은 반드시 한 명만.** 전체 일괄은 그 뒤에.

## Phase 6 — 반복 및 학기 전환

- [ ] 다음 과제로 Phase 2~5 반복
- [ ] 2학기: `.env`의 `COURSE_ID`만 교체

## 하지 말아야 할 것

| ❌ | 이유 |
|---|---|
| 저장 엔드포인트 파라미터 추측해서 직접 POST | 성적 손상 위험. 되돌리기 어려움 |
| 로그인 캡차 우회 시도 | 시스템의 명시적 의도를 거스름 |
| 요청 병렬 폭주 | 학교 서버 부담. 차단 사유가 됨 |
| 학생 데이터 커밋 | `.gitignore`에 `data/` 포함되어 있음. 확인하고 커밋할 것 |
| 담당 외 과목 접근 | 권한 범위를 넘어섬 |
| 사람 검토 없이 일괄 저장 | AI 초안은 초안입니다. 최종 책임은 교수자에게 있습니다 |
