# 01. 핵심 발견 사항

> 화면 탐색과 네트워크 요청 분석을 통해 파악한 내용. 마스킹된 식별자는 실제 값이 아닙니다.

## 1.1 이 시스템은 REST API가 아니다

기대했던 깔끔한 REST/JSON 구조가 아니라, **예전 방식의 서버 렌더링 웹앱**입니다
(Struts / JSP 계열로 추정).

| 항목 | 일반적인 REST API | 이 LMS |
|---|---|---|
| URL | `/api/v1/courses/123` | `/lms/myLecture/doListView.dunet` |
| 메서드 | 자원별 GET/POST/PUT/DELETE | 대부분 **POST** (조회조차도) |
| 응답 | JSON | **HTML 조각 또는 페이지 전체** |
| 인증 | Bearer 토큰 / API 키 | **세션 쿠키 `JSESSIONID`** |
| 상태 확인 | 없음 (stateless) | 화면마다 `getSessionInfo.dunet` 반복 호출 |

### 실무적 함의

- HTTP 클라이언트는 **쿠키 자를 유지**해야 한다. 토큰 갱신 로직은 필요 없다.
- 응답 파싱은 JSON 파서가 아니라 **HTML 파서(cheerio)** 가 기본이다.
  단, Tabulator 그리드용 엔드포인트 일부는 JSON을 반환하므로 응답 `Content-Type`으로 분기한다.
- 세션 만료 감지는 `getSessionInfo.dunet` 응답, 또는 응답 본문에 로그인 폼이 섞여 들어오는지로 판단한다.

## 1.2 로그인은 자동화할 수 없다

로그인 화면에 **슬라이더 캡차(slidercaptcha)** 리소스가 존재합니다.
따라서 아이디/비밀번호 자동 제출로는 로그인이 되지 않습니다.

**채택한 방식:** 사람이 브라우저에서 직접 로그인 → 그 시점의 세션 쿠키를 저장 →
이후 수집 작업이 그 쿠키를 재사용. 세션이 끊기면 다시 사람이 로그인.

이건 우회가 아니라 **캡차의 의도를 그대로 존중하는 방식**입니다.
"사람이 한 번 로그인했다"는 사실을 그대로 유지한 채, 그 사람이 손으로 하던 반복 조회만 대신합니다.

## 1.3 메뉴 이동은 링크가 아니라 폼 제출

메뉴는 `href="..."`가 아니라 `javascript:fnGoContent(...)`, `fncGoClassroom(...)` 같은
함수 호출입니다. 이 함수들은 **숨겨진 폼(hidden form)을 만들어 POST로 제출**합니다.

즉, URL만 복사해서는 화면에 갈 수 없고 **어떤 파라미터가 폼에 실리는지**를 알아야 합니다.
확인된 핵심 파라미터는 `course_id`, `class_no` 두 개입니다.

## 1.4 식별자 스키마

세 종류의 ID만 알면 대부분의 화면에 접근할 수 있습니다.

| 식별자 | 예시(마스킹) | 의미 |
|---|---|---|
| `course_id` | `202610UN0060****Y2` | 학기(202610) + 과목코드 + 분반코드가 이어붙은 문자열 |
| `class_no` | `Y2` | 분반코드 (Y1~Y6 형태) |
| `user_no` | `2024*****` | 학생 학번 |
| `report_no` + `report_seq` | `3` + `1` | 과제 식별 (과제번호 + 회차) |

> **2학기 재사용:** `course_id`의 앞 6자리(학기) 와 분반만 새 학기 값으로 바꾸면
> 동일한 로직을 그대로 재사용할 수 있습니다. 코드에 하드코딩하지 말고 `.env`에서 주입하세요.

## 1.5 확인하지 못한 부분 (의도적으로 남겨둠)

과제 채점 화면에는 "선택한 교육생의 점수 일괄 수정" 기능이 있고,
개별 학생 채점 모달에는 "저장" 버튼이 있습니다.

**저장 시 호출되는 실제 POST 엔드포인트**(`doSaveReportMark.dunet` 류로 추정)와
그 파라미터는 확인하지 않았습니다. 실제 학생 데이터를 변경하지 않기 위해
저장 버튼을 누르지 않고 모달을 닫았기 때문입니다.

이 미확인 영역이 바로 [03. 아키텍처](03-architecture.md)에서
**쓰기는 직접 호출하지 않고 브라우저 자동화로 처리**하기로 결정한 이유입니다.
