# 동료평가 학습보조 시스템

전문대 수업에서 학생들이 **서로의 발표·토론·팀 기여·과제를 평가**하고,
그 결과를 집계해 **학교 LMS 성적으로 넘기는** 시스템입니다.

📖 **가이드 사이트**: https://jungaistar.github.io/lms/

---

## 무엇을 하는가

| 활동 | 학생이 하는 일 | 점수가 나오는 방식 |
|---|---|---|
| **발표 상호평가** | 발표 조를 루브릭으로 채점 + 코멘트 | 받은 점수 평균 (극단값 제외) |
| **토론 참여 평가** | 토론방에 글·답글 → 서로 평가 | 받은 점수 평균 |
| **팀 기여도 평가** | 팀원에게 100점 배분 | 균등 배분 대비 기여 배율 |
| **과제 동료 첨삭** | 동료 과제를 읽고 루브릭 + 피드백 | 받은 점수 평균 |

네 활동 모두 **미평가 감점**이 붙습니다. 남을 평가하지 않으면 자기 점수도 깎입니다.

## 공개 정책

- 학생은 **자기가 받은 코멘트만** 봅니다. 누가 썼는지는 표시되지 않습니다.
- **점수는 학생에게 공개되지 않습니다.** 화면에서 감추는 게 아니라, 점수를 반환하는
  API 자체가 학생 토큰에 존재하지 않습니다 (`docs/20-assessment-design.md` 참조).
- 교수는 누가 누구에게 몇 점을 줬는지 전부 봅니다.

## 구조

```
web/       학생·교수 화면 (React + Vite → GitHub Pages)
supabase/  DB 스키마 · RLS 정책 · 집계 함수 · 학생 로그인 Edge Function
bridge/    학교 LMS(*.dunet) 연동 — 명단 가져오기, 성적 넘기기
docs/      설계 문서와 설치·운영 가이드
```

데이터와 권한 통제는 전부 Supabase(Postgres + RLS)에 있습니다.
프론트엔드는 정적 파일이라 서버 운영이 필요 없습니다.

## 시작하기

1. **Supabase 프로젝트를 만들고 스키마를 올립니다** → [docs/10-setup.md](docs/10-setup.md)
2. `web/.env` 에 URL과 anon key를 넣고 `npm run dev`
3. 교수 계정으로 로그인 → 과목 만들기 → 명단 붙여넣기 → 루브릭 → 활동 만들기
4. 학생에게 **수업코드**를 알려주면 학번만으로 들어옵니다

학기 중 실제 운영 순서는 [docs/30-operations.md](docs/30-operations.md)에 있습니다.

## 학생 로그인

학번 + 수업코드입니다. 가입 절차가 없어 첫 수업에서 바로 쓸 수 있습니다.
다만 이건 **본인 확인이 아니라 명단 확인**입니다 — 한계와 대응은
[docs/20-assessment-design.md](docs/20-assessment-design.md#로그인의-한계)에 적어뒀습니다.

## ⚠️ 학교 LMS 연동 전 확인

`bridge/` 는 학교 LMS(BLU 3.0 계열)를 다룹니다. 쓰기 전에:

- 접속 대상이 운영 시스템인지 확인하세요 (조사 당시 화면에 "Demo" 표기가 있었습니다).
- 운영이라면 **소속 기관에 자동화 도구 사용이 허용되는지 먼저 문의**하세요.
- 성적 입력 화면의 셀렉터는 아직 확인하지 못해 `SELECTORS_VERIFIED = false` 로 잠겨 있습니다.
  그 전까지는 CSV를 내려받아 화면에서 직접 입력하세요.
